# 🚀 MockAPI Pro

A modern Mock API platform for frontend developers.

Create Mock APIs instantly, generate secure API keys, test frontend applications without a backend, and monitor usage with built-in rate limiting.

---

## ✨ Features

- 🔐 User Authentication
- 🔑 API Key Management
- 📡 Mock REST APIs
- 🌐 GET, POST, PUT & DELETE Support
- 📊 Daily Request Usage
- ⚡ Rate Limiting
- 📚 API Documentation
- 💳 Pricing Plans
- 📱 Responsive Design

---

## 🛠 Tech Stack

### Backend
- Python
- Flask
- SQLite

### Frontend
- HTML5
- CSS3
- JavaScript

---

## 🚀 Installation

```bash
git clone https://github.com/firozkhan9892/mockapi-pro.git

cd mockapi

cd backend

pip install -r requirements.txt

python app.py
```
