Authentication

Every request to a mock endpoint requires an API key. You can pass it in two ways:

Header: x-api-key

HTTP 
GET /mock/{user_id}/endpoint HTTP/1.1
Host: mockapi.com
x-api-key: mk_live_your_api_key_here

Header: Authorization Bearer

HTTP 
GET /mock/{user_id}/endpoint HTTP/1.1
Host: mockapi.com
Authorization: Bearer mk_live_your_api_key_here

Create REST API Mock

One resource handles all HTTP methods: GET (list), POST (create), PUT (update /id), DELETE (remove /id). Requires session authentication.

POST /api/rest/create

Request Body

JSON 
{
    "name": "Users API",
    "endpoint": "/users"
}

Response (200)

JSON 
{
    "success": true,
    "rest_id": "rm_abc123",
    "name": "Users API",
    "endpoint": "/users",
    "status_code": 200
}

Mock URL base: GET /mock/{user_id}/users — use one API key for all methods. Records are created with POST and referenced by returned id for GET /id, PUT /id, and DELETE /id.

Create Mock API

Use this endpoint to create a new mock API. Requires session authentication (logged in via dashboard).

POST /api/create

Request Body

JSON 
{
    "endpoint": "/users",
    "method": "GET",
    "response": "[{\"id\": 1, \"name\": \"John\"}]",
    "status_code": 200
}

Response (200)

JSON 
{
    "success": true,
    "api_id": 1,
    "url": "http://mockapi.com/mock/{user_id}/users",
    "method": "GET",
    "status_code": 200
}

Request Examples

GET Fetch Mock Data

cURL 
curl -X GET "http://mockapi.com/mock/{user_id}/users" \
  -H "x-api-key: mk_live_your_key_here"
Python 
import requests

url = "http://mockapi.com/mock/{user_id}/users"
headers = {"x-api-key": "mk_live_your_key_here"}

response = requests.get(url, headers=headers)
print(response.json())
JavaScript 
const response = await fetch(
  "http://mockapi.com/mock/{user_id}/users",
  {
    headers: {
      "x-api-key": "mk_live_your_key_here"
    }
  }
);

const data = await response.json();
console.log(data);

POST Create Resource

cURL 
curl -X POST "http://mockapi.com/mock/{user_id}/users" \
  -H "x-api-key: mk_live_your_key_here" \
  -H "Content-Type: application/json" \
  -d '{"name": "Alice", "email": "alice@example.com"}'
Python 
import requests

url = "http://mockapi.com/mock/{user_id}/users"
headers = {
    "x-api-key": "mk_live_your_key_here",
    "Content-Type": "application/json"
}
payload = {"name": "Alice", "email": "alice@example.com"}

response = requests.post(url, json=payload, headers=headers)
print(response.json())
JavaScript 
const response = await fetch(
  "http://mockapi.com/mock/{user_id}/users",
  {
    method: "POST",
    headers: {
      "x-api-key": "mk_live_your_key_here",
      "Content-Type": "application/json"
    },
    body: JSON.stringify({
      name: "Alice",
      email: "alice@example.com"
    })
  }
);

const data = await response.json();
console.log(data);

Error Codes

Code Description
200 Success. Request completed successfully.
401 Unauthorized. Missing or invalid API key.
404 Not Found. Mock endpoint does not exist for the given method.
429 Rate Limited. Daily request limit reached. Upgrade to Pro.
500 Server Error. Something went wrong on our end.

Error Response Format

JSON 
{
    "error": "Invalid API key"
}

Frequently Asked Questions

Where do I find my API key?

Go to your Dashboard. Click "+ Create Key" in the API Keys section. Copy the key immediately as it won't be shown again.

What is the daily request limit?

Free plan: 250 requests/day. Pro plan: 50,000 requests/day. The limit resets at midnight UTC.

Can I use both x-api-key and Bearer token?

Yes. Both methods are supported. Use whichever is more convenient for your setup.

How many mock APIs can I create?

Free plan: 5 mock APIs. Pro plan: Unlimited. Each mock can have multiple HTTP methods on the same path.

What happens if I hit 429?

Your request is rejected. Wait until midnight UTC for the limit to reset, or upgrade to Pro for higher limits.

Is there a sandbox for testing?

Yes. The Free plan acts as a sandbox. Create mock APIs and test your frontend without any cost.
