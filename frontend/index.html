Frequently Asked Questions

What is MockAPI?

MockAPI lets you create fake REST API endpoints for testing and development. Define your response JSON and use the URL in your frontend code.

Is it really free?

Yes. The free plan includes 5 mock APIs and 250 requests per day. No credit card required to sign up.

Do I need an API key?

Yes. Every request to a mock endpoint requires an API key passed via the x-api-key header or Authorization Bearer token.

What happens when I hit the daily limit?

You'll receive a 429 response. You can upgrade to Pro for 50,000 requests/day, or wait for the limit to reset at midnight UTC.

Can I use MockAPI in production?

MockAPI is designed for development and testing. For production, use a real backend service.
